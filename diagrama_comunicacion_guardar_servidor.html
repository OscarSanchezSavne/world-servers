⚠ INCONGRUENCIAS DETECTADAS

❗ #1 — Height no contempla ValidateError

modal_register_server_view.rs líneas 19-24:
if state == Idle { height=500 } else { height=100 }

ValidateError renderiza el mismo formulario pero recibe height=100 → fixed_size(560, 0) rompe el layout.

💡 Fix: if matches!(state, Idle | ValidateError(_)) { height=500 } else { height=350 }

❗ #2 — Comentario «REVISAR ESTA VISTA CON EL ASISTENTE»

Línea 3 de modal_register_server_view.rs. Parece un TODO del desarrollador que quedó sin resolver.

💡 Fix: Eliminar la línea o convertir en un comentario // TODO: concreto.

❗ #3 — Cierre inconsistente del modal

Botón «X» solo pone show=false.
cancel_server_form() resetea todo con ServerForm::new().

Si el usuario cierra con X y reabre, el estado anterior (log, errores) persiste.

💡 Fix: Al detectar !open llamar también a cancel_server_form().

❗ #4 — Altura fija no se adapta al log

Estados Running/Done/Error usan altura fija de 100px, pero el panel de log crece con cada mensaje SSH. No hay scroll ni altura dinámica.

💡 Fix: Usar egui::ScrollArea en el panel de log y quitar fixed_size.
